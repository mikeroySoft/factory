The diff needs one fix: it collects PR feedback one PR at a time, with no limit on the total, inside every full snapshot. I couldn't use `gh` here, so I read issue #79 and its comments from the public GitHub page.

## Standards
- The snapshot has no AGENTS.md or CONTRIBUTING.md. `docs/` holds only planning files.
- The conventions the README does state are followed: no new Python dependencies, and the CHANGELOG entry under "Unreleased" references the issue (#79).
- The new UI text goes through the existing `h()` / `pre()` helpers as text nodes, and links pass through `safeSourceURL`. Provider text can't be injected as HTML.

## Spec
Schema 1, canonicalization, the fixed bounds, the head-race handling and keeping `--runtime-json` network-free all match the issue. The Factory-review provenance check matches what `dispatch.review` actually writes: the `result` event fields and the `approved` / `product_feedback` exit outcomes. Ownership depends on the `Closes #n` line that dispatch already puts in PR bodies.

The blocking defect is the per-PR cost of collection:
- **Before:** one full snapshot made one `gh` GraphQL call.
- **After:** it also calls `feedback.collect` for every selected agent PR, open or merged, one after another. Each PR costs at least 6 `gh` subprocesses and can take up to 30 seconds.
- **Where it runs:** under `_cache_lock`, refreshed every 15 seconds, polled by the UI every 30 seconds, and again on each Inbox `?fresh=1`.
- **Effect:** the issue says "Preserve full-snapshot cadence". That breaks once there are a few dozen agent PRs.

## Plan drift
- **Files:** no worker plan was recorded. Every changed file is named in the issue's "Touches" list; `tests/test_feedback.py` is explicitly allowed.
- **Missing proof:** the gate report covers only exit-gate step 6, the unittest run. There is no record of step 5: the real `python -m factory dashboard --json` run, the browser check of the Review drawer and Inbox, and inspecting `sources_for` against the same snapshot. Step 7, the #15 handoff, is also unrecorded. A smoke run with many PRs would have shown the cadence problem.
