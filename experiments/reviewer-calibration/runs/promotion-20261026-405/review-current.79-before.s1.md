The gate report has no proof for exit-gate items 5 and 7 (the CLI, browser and briefing smoke run, and the #15 handoff). That missing proof does not expose a required defect by itself.

**Important findings:**
1. **Snapshot cadence (`dashboard.py:883`).** Feedback is now collected for every `agent/<n>` PR in the latest 100, merged and closed ones included. Each PR takes one at a time, 6–8 `gh` calls, with up to 30 seconds allowed per PR. All of this runs while the snapshot cache lock is held, and the dashboard rebuilds the snapshot every 15 seconds and polls every 30. Before this change a snapshot was one GraphQL call. With many PRs, a snapshot can take minutes (up to about 50 at the limits). It blocks every request in the meantime and uses up the API rate limit the dispatcher shares.
2. **Wrong producer revision (`dashboard.py:875`).** The revision comes from `git rev-parse HEAD` run in the installed package's directory. If Factory is installed into a git-ignored virtualenv (or any directory) inside another git repository, that command returns the other repository's HEAD. The clean-tree check is empty because the directory is ignored. So `producer.revision` reports an unrelated commit when the issue and README require a verifiable source revision or null.
